> **359th Brigade Red Cultural AI Workflow System 2.0**

## 🌟 核心重构与系统亮点

### 模块一：智能多轮问答（屯垦智答·双轨可溯源对话系统）
- **UI 呈现**：标准对话聊天流（左侧 AI 导师、右侧用户、底部固定输入框、推荐快捷问题胶囊）。
- **双轨知识库机制**：
  1. **内置权威史料库**：预置 5 篇三五九旅权威历史档案（进驻阿克苏开荒、第一把坎土曼打铁淬火、南泥湾精神到兵团精神自力更生老纺车、百里胜利渠冰水打桩、多民族兵地共建石榴籽深情）。
  2. **一手实地调研素材即时追加**：提供【录入调研访谈】弹窗，支持粘贴“老军垦口述录音整理”（如 93 岁老战士张文生打铁手心血泡实录）或田野调研笔记，系统毫秒级载入当前向量检索池（N-Gram + TF-IDF 余弦相似度）。
- **事实考据与无幻觉溯源**：
  - AI 严格基于双轨知识库上下文作答，每句事实后标注 `[1]`、`[2]` 角标；
  - 回答气泡下方提供【参考来源与考据溯源切片展开板】，清晰展示引用的文献标题、出处档案、相似度得分、原文摘录，并打上【权威史料】或【一手访谈】的区分标签。

### 模块二：新媒体全案传播策划与自动问卷生成
输入传播主题（如“让三五九旅第一把坎土曼走进青年”），一键生成四联版全案：
1. **小红书爆款图文**：吸睛封面设计构思、融入当代青年精神内耗与奋斗痛点的爆款正文、情绪与文旅标签（#三五九旅 #军垦青年 #第一把坎土曼），附一键复制按钮。
2. **抖音/视频号短视频分镜**：包含 4-5 个精细分镜头表格（时码、景别、画面动作、音效配乐、台词旁白）。
3. **《三五九旅红色文化青年传播效果调查问卷》（标准 Markdown 格式）**：
   - 包含受访者基础人口学画像（年龄、民族、高校/职业）；
   - 屯垦历史认知度单选与触达渠道多选题；
   - **5 级李克特量表认同题**（奋斗共鸣、民族团结认同、生活史视角共情等）；
   - 实体文创接受度与购买意愿选择题；
   - 开放式改进建议题；
   - **支持一键复制问卷 Markdown 文本，并支持一键下载导出 `.md` 文件**。

### 模块三：红色文创概念图与设计方案生成（实用生活文旅实体）
拒绝空洞插画，深度聚焦具体的日常实用文旅文创实体：
- **5 款实用载体库自由切换**：
  - **便携手持小风扇**（戈壁清风概念、防卷发扇叶、手柄坎土曼浮雕握感、Type-C 应急快充）
  - **军垦拓荒刺绣帽子**（天山印记、16安重磅水洗做旧帆布、阿克苏经纬度坐标微标）
  - **戈壁拓荒多功能保温杯**（多浪清泉、哑光战壕绿、激光微雕百里胜利渠水文线、智能触摸数显）
  - **军垦拓荒工装帆布袋**（由战转耕、20安超厚棉麻、手工铁扣件、开荒纪念图章丝印）
  - **金属复古浮雕冰箱贴**（红柳记忆、双层锌合金压铸、红星软珐琅、暗夜微光涂层）
- **工业级设计成果交付**：
  1. **工业设计规格说明**：色彩 Palette 定义、工艺与表面材质（哑光喷砂、重磅帆布、316L微雕等）、文旅场景功能点。
  2. **商业摄影生图 Prompt**：纯白底商业产品摄影级别中英文提示词（包含 professional product studio photography, clean white background, soft studio lighting, sharp focus, 8k resolution 等）。
  3. **视觉渲染大图展示**：调用极速生图接口渲染商品图，支持全屏大图查看与一键高清下载。

### 全局配置抽屉与高保真 Mock Fallback
- 右上角抽屉随时配置 API Key 与基座模型（支持 Gemini 3.8 Flash、DeepSeek 等）。
- **零配置开箱即跑**：若未填写 API Key，系统自动激活内置高质量三五九旅专家研习库，流式打字机、分镜表、调查问卷与文创商品图全流程丝滑展现，答辩演示 100% 稳定永不报错白屏。

## 🚀 一键热重载与查看效果指南

### 1. 安装依赖（若首次运行）
```powershell
cd C:\Users\Lenovo\tunken_zhida
pip install -r requirements.txt
```

### 2. 启动服务（热重载模式）
在终端中执行以下命令，即可在代码修改时自动热重载：
```powershell
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
或者直接使用项目自带的一键启动器（自动打开浏览器）：
```powershell
python run.py
```

### 3. 访问与体验
在浏览器打开：
👉 **http://127.0.0.1:8000**
- 点击顶部 **“💬 智能问答与调研库”**：点击快捷提问体验流式打字与参考来源展开板，点击右上角“录入调研访谈”尝试追加老军垦张文生口述实录并即时检索；
- 点击顶部 **“📢 传播方案与问卷”**：点击一键生成，查看小红书文案、抖音 4 镜分镜表与标准 Markdown 调查问卷，并测试一键复制与导出 `.md` 文件；
